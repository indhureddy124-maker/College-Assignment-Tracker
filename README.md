# College Assignment Tracker

A simple, responsive assignment manager built with **HTML, CSS and JavaScript**. It helps students organise coursework, due dates and priorities.

## Features

- Add assignments with a title, subject, due date and priority.
- Edit existing assignments.
- Mark assignments as completed or pending.
- Delete assignments.
- Search by assignment title or subject.
- Filter by completion status.
- View total, pending and completed assignment counts.
- Automatically save assignments in the browser using `localStorage`.
- Responsive layout for desktop and mobile screens.

```text
College-Assignment-Tracker/

```

## How to run

1. Download and extract the ZIP file.
2. Open the `College-Assignment-Tracker` folder.
3. Double-click `index.html` to open it in a modern web browser.
4. Add an assignment using the form.

No installation or server is required.

## Data storage

Assignments are saved in the browser's local storage on the device and browser where the project is opened. Clearing browser data may remove saved assignments. This project does not use an online database or account system.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage
